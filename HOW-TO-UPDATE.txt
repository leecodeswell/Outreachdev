Outreachdev website, version 24 (complete; includes everything from v23)
=========================================================================

1) WEBSITE (GitHub repo)
   Easiest: "Add file" > "Upload files", drag in EVERYTHING inside this folder (the files and the
   folders, not this outer folder), commit to main. Uploading replaces files with the same name and
   never deletes anything. Your live Stripe links and Firebase settings are already inside.

   Or upload only what changed since v22:
     index.html, terms.html (new), privacy.html (new), script.js, style.css,
     scheduling-agent.html, work-order-manager.html,
     scheduling-agent/  app.css  app.js  config.js  firestore.rules  solver.js
     work-orders/       app.css  config.js  wo-app.js  wo-store.js

2) BACKEND + SECURITY RULES (from scheduling-agent-backend-v24.zip, which stays on your computer)
   a. Extract it, then in VS Code: File > Open Folder > the "scheduling-agent-backend" folder inside.
   b. In the terminal:
        cd functions
        npm install
        cd ..
        firebase deploy --only functions,firestore:rules
      Your secrets (Anthropic key, Stripe signing secret) are stored by Google, so you don't set them again.
      If it times out: $env:FUNCTIONS_DISCOVERY_TIMEOUT="60"  then run the deploy again.
   The rules update is required for deleting work orders.

3) CHECK
   - Homepage: the new orb and leaves (Ctrl+F5 if it looks old).
   - Footer: Terms and Privacy links.
   - Work Order Manager: Light/Dark is on the first setup screen; Delete on an order; the assistant
     can create, edit and delete orders, customers and team members.
   - Scheduling Agent: ask the Helper to add a shift, change someone's hours, or give someone a day off.
